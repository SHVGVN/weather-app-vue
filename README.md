# Pixel Weather

Застосунок погоди в стилі піксель-арт на Vue 3 та OpenWeatherMap API.

## Стек

- Vue 3 (Composition API, `<script setup>`), TypeScript, Vite
- Pinia, Vue Router, Vue I18n
- Chart.js без обгорток (`vue-chartjs` не використовується)
- Власні стилі без CSS-фреймворків і UI-бібліотек, піксельні шрифти Tiny5, Jersey 10 і Press Start 2P з Google Fonts
- Vitest, ESLint, Prettier

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

У `.env` потрібно вказати ключ OpenWeatherMap:

```
VITE_OWM_KEY=your_openweathermap_api_key
```

| Команда | Опис |
| --- | --- |
| `npm run dev` | Dev-сервер |
| `npm run build` | Перевірка типів і продакшн-збірка |
| `npm run preview` | Перегляд збірки |
| `npm run test` | Unit-тести |
| `npm run lint` | ESLint |

## Функціональність

1. Інпут з автокомплітом міст (Geocoding API): debounce, скасування застарілих запитів, керування з клавіатури (↑ ↓ Enter Esc).
2. Запити через `fetch` з невеликою обгорткою.
3. Картка погоди на поточний день.
4. Графік температури по годинах на Chart.js, екземпляр створюється і знищується вручну.
5. До 5 блоків погоди, кнопка «+» додає блок з повним функціоналом, за замовчуванням завжди є 1 блок.
6. Видалення блоку з підтвердженням у модальному вікні.
7. Вкладка «Вибране»: додавання і видалення міст, відмітка зірочкою та золотою рамкою, збереження в `localStorage`, максимум 5 міст. Якщо ліміт перевищено, модальне вікно пропонує видалити одне з міст і одразу додає нове.
8. Адаптивна верстка: контейнер 1200px, мінімальна ширина 360px.
9. Перемикання «День / 5 днів»: картки по днях і графік середньої температури, розрахованої з 3-годинного прогнозу. Дні групуються за часовим поясом міста.
10. Місто користувача за IP з кількома резервними сервісами (ipwho.is → geojs.io → ipapi.co). Якщо вони недоступні, показується Київ.
11. Прелоадери для пошуку, визначення локації та завантаження погоди.
12. Мультимовність en/uk для інтерфейсу і відповідей API (`lang`).
13. Перемикання «День / Ніч» з анімованим фоном: сонце заходить за горизонт, на небі зʼявляється закатне світло, сходить місяць і проявляються зорі. Інтерфейс плавно змінює палітру. Перша тема обирається за часом доби, вибір зберігається.

## Додатково

- Перемикач одиниць °C / °F.
- Анімований фон відображає погоду першого міста на сторінці: кількість і колір хмар, сірість неба, дощ, гроза з блискавками, сніг, туман, сяйво сонця в ясну погоду.
- Видалення карток з анімацією «шредера».
- Блоки головної сторінки зберігаються між перезавантаженнями.
- Кнопка оновлення даних у кожному блоці.
- Кешування відповідей API (погода 10 хв, геокодинг 24 год), щоб не впиратися в ліміти безкоштовного тарифу.
- Власні піксельні іконки погоди, що генеруються як SVG з піксельних сіток.
- Модальні вікна на нативному `<dialog>`: фокус всередині вікна, закриття по Esc і кліку на фон.
- Обробка помилок API (невірний ключ, ліміт запитів, відсутність мережі) з можливістю повторити запит.
- Unit-тести для агрегації прогнозу та відповідності погоди і фону.

## Примітка щодо погодинного графіка

Безкоштовний тариф OpenWeatherMap надає прогноз з кроком 3 години (`/data/2.5/forecast`), тому графік на поточний день будується з поточної температури та 3-годинних точок до кінця доби. Якщо до кінця доби лишилося менше трьох точок, графік показує найближчі 24 години.

## Деплой

Конфігурація для SPA-маршрутизації вже додана для Vercel (`vercel.json`) та Netlify (`public/_redirects`). У налаштуваннях хостингу потрібно додати змінну середовища `VITE_OWM_KEY`.
